# CPE Preparation Exercises

A central repository documenting my practice solutions and problem-solving journey while preparing for the **Computer Proficiency Examination (CPE)**. 

## 📂 Repository Structure
To keep things organized, each challenge is structured under a matching naming convention:
* **`[Problem Name].pdf`**  – The original exam question and constraints.
* **`[Problem Name].cpp`** – My optimized source code solution.

## 🚀 Goals
* Document continuous learning and daily coding consistency.
* Master core algorithms, low-level string manipulations, and data structures.
* Track preparation milestones for engineering assessments.
